# 안시성 모바일 기획안 제작과 배포

작성 2026-11-22 20:41 KST

[이전 계획](2026-11-22_2004_안시성_시나리오_기획안.md)에서 첫 공개 기준을 변경한다. 대표 인물과 거점으로 모바일 열람을 먼저 제공하고, 국가별 100인 편성 결과를 조사 순서대로 추가한다.

## 구현

- 한 편의 시나리오 선택에서 5국 개념도, 14개 거점, 인물 열전, 첫 내정 직전 브리핑으로 이동한다.
- 인물은 이름·이명, 국가, 역할, 배치 여부로 조회한다. 열전에는 근거와 능력치의 설계값 여부를 기록하고, 국가별 등록 인원을 100명 목표와 함께 표시한다.
- 첫 공개 검증은 모바일 지도와 목록, 거점과 인물 링크, 검색, 뒤로 가기, 직접 접속을 포함한다. 최종 편성은 500명의 고유 ID, 사료 근거, 활동 시기와 배치를 대조한다.

## 개발과 게시

- 기존 개발 지침을 따른다. 사료·작품 배역·설계값을 분리하고 미확인 수치는 화면에서 미확인으로 표시한다. 원본 저장점은 보존한다.
- `scenario-preview/`의 정적 파일만 GitHub Actions에서 Pages 아티팩트로 게시한다. 저장소의 Pages Source는 GitHub Actions를 사용한다.
- `main`에 반영된 변경의 배포가 성공한 뒤 실제 공개 URL을 확인한다. 새 계획은 `plan/YYYY-MM-DD_HHmm_이름.md`로 보관한다.

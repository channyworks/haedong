# HAEDONG 개발 작업 지침

WORLD.md, GAME_DESIGN.md, API_CONTRACT.md, ../07_GameData/unknowns.json, ../09_References/source_hashes.json을 먼저 읽는다.

- 역사 H / 기존 게임 G / 신규 창작 N / 미확인 U를 필드로 분리한다.
- 원본 저장점과 v01_original은 읽기 전용으로 취급한다. 기존 수치를 고칠 때에는 원본 교체 대신 새 migration과 사유를 추가한다.
- 새 엔진 기능은 회계·상태 불변·멱등·재현 테스트를 먼저 작성한다.
- U는 null이며 0으로 치환하지 않는다. 가용병력 차이를 전사로 추론하지 않는다.
- 모델은 JSON 행동 제안만 작성한다. 수치 변경·시간 진행·주사위·승패·권한 판정은 Python 엔진만 담당한다.
- MySQL 권위 상태, LangGraph 체크포인트, 서사 텍스트를 분리한다. AI 대기 중 트랜잭션 잠금을 잡지 않는다.
- 직속군·독립군·귀환민·포로·수레·물량·지수의 회계를 분리한다.
- 분기 B는 참조 기록이다. 새 플레이에 같은 결말을 강제하지 않는다.
- 생성 그림과 지도는 역사적 실측 복원이나 실제 초상이 아니다.
- 본 패키지는 설계·데이터·검증 기준 커널이다. 전체 FastAPI/Vue 게임이 구현됐다고 보고하지 않는다.

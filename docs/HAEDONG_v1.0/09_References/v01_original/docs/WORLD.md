# 공통 세계관 v0.1
범위: 645년 안시성 공방전 분기 B, 17일차 10시부터 150일차 13시. 이전 공방전은 서장 배경으로만 사용하며 정확한 일별 기록은 미확보.
역사(H): 645년 당 태종의 고구려 원정, 안시성 저항, 토산의 상실과 당군 철수는 역사적 골격. 성주의 양만춘 이름은 후대 전승이며 동시대 기록에서 확정되지 않는다. 보장왕·연개소문·이세민·이세적·이도종 등은 실존 인물. 참고할 사료: 삼국사기 고구려본기 보장왕 4년, 자치통감 당기 정관 19년, 구당서·신당서 고구려 관련 열전. 이번 판에서 사료 원문 대조는 미실시.
게임(G): 병력, 날짜의 상대 일차, 토산 진행률, 협곡 전투, 휴전 조건, 포로 교환, 양덕 부임, 관등 및 능력치는 창작 분기. 실제 고연수의 행적과 게임 배역은 다르다. 북동 산성은 가상 거점이다.
소설(N): 대사·심리·날씨의 세부 묘사는 창작. 사건 결과를 임의 변경하지 않는다. 군령 시점에 알 수 없었던 첩보는 전지적 별도 장면에만 사용한다.
미확인(U): B022 상세 보고 및 POST_000~002의 전체 원문, 초기 17일 이전 기록. 복원 요약은 원문으로 취급하지 않는다. B008은 B008R로 대체되므로 중복 집계 금지.
시간: 상대 일차와 역사 달력을 별도 필드로 보존. 정확한 절대 날짜는 미확정. 150일차 겨울은 게임 서사 표기.

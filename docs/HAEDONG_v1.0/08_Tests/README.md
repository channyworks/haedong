# 검증 실행

패키지 루트에서 Python 3.10 이상으로:

```bash
python -m unittest discover -s 08_Tests -v
```

표준 라이브러리만으로 핵심 검증 실행. jsonschema가 있으면 두 스키마도 검사하고 없으면 해당 한 항목만 skip한다. 이미지 생성이 끝난 후 실행해야 파일 누락 검사가 통과한다.

검증 범위: 업로드 원본 해시와 바이트 동일성, 최종 병력·포로 합계, null·대체 저장점, 파생 사건 참조, 인물 초상·지도 파일, 신규 기준 커널의 상태불변·멱등·버전·정수·전투 난수 재현·중단시간.

한계: 실제 전쟁 중간 원장과 물량은 자료가 없어 검증 불가. MySQL 동시성/FastAPI 네트워크/Vue/LangGraph/Ollama 통합 시험 미실시. 커널은 완성 게임 엔진이 아니다.

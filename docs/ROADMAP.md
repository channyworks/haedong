# 로드맵

| 단계 | 우선순위 | 종료 기준 |
|---|---|---|
| PoC | 안시성 기획안으로 콘텐츠·시나리오·PC 및 모바일 UX 검증. 기준 커널로 핵심 시뮬레이션 규칙 검증. 기존 저장소와 무료 GitHub Pages 사용. | 로컬과 공개 URL에서 주요 탐색 흐름을 검증하고 핵심 데이터·시뮬레이션 검증 결과와 후속 요구를 기록한다. |
| MVP | Pages 공개 종료와 저장소 Private 전환. 소설과 게임을 통합하고 Vercel, GitHub OAuth, Auth.js 후보를 검토한다. | 소유자 GitHub 고유 ID만 접근하고 페이지·API·직접 파일·미리보기 URL의 미인증 접근이 차단된다. |
| 정식 서비스 | 콘텐츠 관리, 열전, 전략·전술 지도, 시뮬레이션, 저장점, DB, 사용자 관리, DEV/PROD, CI/CD, 모니터링, 백업·복구를 요구에 따라 구현한다. | 운영 책임, 장애 복구와 배포 검증 기준을 정하고 실제 서비스에서 검증한다. |

현재 우선순위는 공개 적합성 결정, Pages 게시와 실기기 검증, 5국 인물·거점 출처 보강 순이다. PoC에는 로그인, 유료 호스팅, Cloudflare, 정식 게임 엔진 배포를 포함하지 않는다.

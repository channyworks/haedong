# ADR-004 MVP에서 Vercel 및 GitHub OAuth 검토

상태 검토 예정 · 2026-11-22

- **배경** MVP는 소설과 게임을 소유자에게 제한해야 한다.
- **결정** Vercel Private 연동, GitHub OAuth, Auth.js와 서버의 GitHub ID 허용 목록을 후보로 삼는다.
- **대안** 사설 호스팅, 다른 인증 서비스
- **선택 이유** 기존 GitHub 계정을 활용하며 서버 기반 권한 검증이 가능하다.
- **장단점과 위험** 인증 도입이 가능하지만 요금제·미리보기 보호·API 및 파일 권한을 검증해야 한다.
- **재검토 조건** MVP 착수 때 기술 스택과 요금제·정책을 다시 비교한다.

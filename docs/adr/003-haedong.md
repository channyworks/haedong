# ADR-003 scenario-preview 기반 GitHub Actions 배포

상태 채택 · 2026-11-22

- **배경** 기존 자료와 루트 테스트 페이지가 기획안과 같은 저장소에 있다.
- **결정** main의 변경으로 워크플로를 실행해 허용된 기획 파일만 사이트 루트에 게시한다.
- **대안** 브랜치 루트 또는 docs 폴더 직접 게시
- **선택 이유** 기존 디렉터리를 보존하면서 Pages 파일 범위를 검증한다.
- **장단점과 위험** 권한과 자료 범위가 명확하다. 새 애셋은 검사 및 허용 목록에 반영해야 한다.
- **재검토 조건** 빌드 단계·콘텐츠 구조·Pages 정책이 달라지면 검토한다.

# ADR-005 저장소 기반 AI Agent 컨텍스트 관리

상태 채택 · 2026-11-22

- **배경** 채팅 세션과 기억 없이도 개발을 이어갈 수 있어야 한다.
- **결정** AGENTS와 프로젝트 문서, ADR, 날짜별 계획을 작업 단서로 관리한다.
- **대안** 채팅 요약, 외부 위키만 관리
- **선택 이유** 코드와 문서 변경을 같은 이력에서 추적한다.
- **장단점과 위험** 인수인계가 개선되며 현황 문서가 낡으면 잘못된 결정을 유도한다.
- **재검토 조건** 문서의 역할이 겹치거나 실제 작업과 어긋날 때 합친다.

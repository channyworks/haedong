# ADR-002 기존 저장소를 PoC 기간에 Public으로 운영

상태 채택 · 2026-11-22

- **배경** 현재 요금제에서는 비공개 저장소의 Pages가 차단된다.
- **결정** 공개 적합성 검토와 권리자 확인 후 사용자가 기존 저장소의 가시성을 변경한다.
- **대안** 별도 공개 저장소, 유료 비공개 Pages, 로컬 유지
- **선택 이유** 파일 복제 없이 기존 Git 흐름을 유지한다.
- **장단점과 위험** 기존 소스와 이력 전체가 공개되며 외부 사본은 회수할 수 없다.
- **재검토 조건** 첨부·이력 검토에서 제한 자료를 발견하거나 PoC를 종료할 때 검토한다.

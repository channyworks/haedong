# ADR-001 PoC 단계에서 GitHub Pages 사용

상태 채택 · 2026-11-22

- **배경** 로컬 PC가 꺼져도 모바일로 기획안을 열어야 한다.
- **결정** PoC는 GitHub Pages 무료 정적 호스팅을 사용한다.
- **대안** 로컬 서버, Vercel, Cloudflare Pages
- **선택 이유** 서버와 결제 설정 없이 GitHub에서 배포를 운영할 수 있다.
- **장단점과 위험** 자동 배포가 간단하다. 서버 기능과 앱 접근 제어가 필요한 단계에는 제약이 있다.
- **재검토 조건** 인증이 필요하거나 이용 정책이 바뀌면 검토한다.

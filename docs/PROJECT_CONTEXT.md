# 프로젝트 컨텍스트

《해동연의》는 645년 고구려와 당의 안시성 공방을 바탕으로 한 역사소설이다. 《해동삼국지》는 같은 사건·인물·세력 자료를 이용해 준비와 지휘에 따른 다른 결과를 탐색하는 게임 구상이다. 기존 분기 B는 작품과 시나리오를 읽는 기준 기록이며 신규 플레이의 결과는 엔진 상태와 선택에 따른다.

## 보존 산출물

- [v1.0 패키지 색인](HAEDONG_v1.0/README.md)에서 완결 소설, 시나리오북, 20인 설정집, 삽화 20점, 비축척 지도 12종을 읽을 수 있다.
- [시나리오북](HAEDONG_v1.0/02_Scenario/SCENARIO_BOOK.md)은 상대 일차별 저장점과 사건을 담는다. START는 상대 17일 10시이며 역사 연월일로 환산하지 않는다.
- [세계관](HAEDONG_v1.0/06_Codex/WORLD.md), [게임 설계](HAEDONG_v1.0/06_Codex/GAME_DESIGN.md), [API 계약](HAEDONG_v1.0/06_Codex/API_CONTRACT.md)과 Python 기준 커널이 있다. 게임 데이터와 원본은 패키지의 07_GameData와 09_References에 있다.

## 현재 결정

5국 세력지도, 거점, 열전, 내정 직전 브리핑을 정적 PoC로 검증한다. 국가별 100명은 장기 편성 목표다. 인물의 실존 여부, 게임 배역, 능력치 설계값을 구분한다. H/G/N/U의 기존 구분과 직속군·독립군·포로 회계를 따른다. MVP 프레임워크·호스팅·권한 세부 구현은 전환 시 검토한다.

## 통합 기획과 도감

- 기존 5국 군령·저장·소설 시연에 통합 인물 도감, 국가 특성·정치·가문, 외교·전선, 변경 세력, 성장·노화, 연표와 발해를 추가했다. 시나리오 27건과 세력 23건이 있으며 6개 국가 정치도와 14개 가문이 포함된다. 연표에서 실행 가능한 캠페인은 기존 645년 시연이다. [통합 기획](design/WORLD_DESIGN.md)
- 도감 199건의 등급은 A 45, B 2, C 2, U 150이다. 이전 목록 전체는 미확보 상태이며 신규 조사 항목 12건과 첨부 표 기반 게임 능력치 91건을 추적한다. [원본 회수 기록](history/ROSTER_AUDIT.md) · [검증 보고서](history/SOURCES.md)
- 전략 AI가 다섯 국가와 여섯 변경 세력의 턴별 판단을 계산한다. 수동·관전·결과 진행은 같은 645년 군령 판정을 사용한다. 실제 정식 전역 엔진과의 연결은 설계 단계다. [정치·AI 설계](design/POLITICAL_SYSTEMS.md)
- Node 시연 회귀와 Python 데이터 검증을 추가했다. 로컬 Chrome 1280px·390px와 직접 파일 실행에서 도감 검색·필터·모달, 정치도와 연표, AI, 기존 지도와 플레이 진입을 확인했다. Windows 체크아웃 설정을 보존 패키지의 LF 바이트 기준에 맞췄다.
- Pages 아티팩트는 검증한 정적 파일만 기존 루트와 `/haedong/scenario-preview/`에 제공한다. 원고·이미지·자료 압축본은 아티팩트 범위 밖이다. [배포 가이드](DEPLOYMENT_GUIDE.md)

## 5국 플레이와 소설 시연

- 645년 5국 선택, 입문용 고구려 안시성, 네 턴의 군령과 세력별 목표를 구현했다. 브라우저에서 판을 복원하고 역사 배경과 플레이 이력 기반 소설 초안을 편집·저장할 수 있다. [5국 플레이와 소설 설계](PLAY_TO_NOVEL.md)
- 현재 등록은 거점 35곳, 기록·전승 인물 112명, 창작 인물 1명이다. 고구려 17 / 백제 23 / 신라 23 / 왜 25 / 당 24명이 국가별 100인 목표의 현재치다.
- 정사·금석문·야사·전승·창작 출처와 기록 시기를 표시한다. 지도는 공개 해안선과 출처를 단 거점 위치를 사용한다.
- 지도·열전 데이터와 5국 판정 검사는 `node --test scripts/check_scenario.cjs`로 실행한다. 로컬 Chrome 1280px와 390px 에뮬레이션에서 각 세력 완료, 이력 복원과 초안 다운로드를 확인했다.
- 배포 커밋 `66e1f7e398816697c9d40c70d7b6becb4b53da2b`의 [Pages 실행](https://github.com/channyworks/haedong/actions/runs/45023640764)이 성공했다. [공개 URL](https://channyworks.github.io/haedong/)에서 같은 두 화면 크기로 거점·출처 조회, 5국 플레이, 이력 복원, 소설 편집과 다운로드를 재검증했다.

## 공개 상태와 검토 사항

- 원격 저장소가 Public으로 전환된 상태에서 배포가 실행됐다. 이번 작업에서는 저장소 공개 범위를 변경하지 않았다.
- 현재 파일과 접근 가능한 이력의 136개 기존 경로·객체 조합을 검토했다. 텍스트, ZIP·Word 내부의 텍스트, PDF 추출 텍스트·메타데이터, 이미지 EXIF 문자열에서 지정한 자격 증명 및 내부망 URL 패턴이 발견되지 않았다. 패턴 검사는 민감정보 부재를 보증하지 않는다.
- Git 커밋 메타데이터에서 작성자·커미터 이메일 유형을 확인했다. `09_References/production_brief.jpg`는 내부 제작 대화 캡처다. 해당 이미지, `09_References/haedong_v01.zip`, v1.0 원고·제작 자료의 저장소 공개 적합성은 권리자 확인이 필요하다.

# 시나리오 연표와 확장

연표의 [정본 JSON](../../data/history/scenarios.json) 27건은 `start_year`, `end_year`, `faction_ids`, `history`, `victory`, `sources`를 가진다. `faction_ids`는 해당 시기와 이후 분기에서 다룰 참여 세력이다. 특정 해의 참여 가능 여부는 국가의 활성 연대와 함께 확인한다. `playable=legacy_645`인 안시성 카드에서 기존 실행 화면으로 이동하며, 다른 연표의 승리 조건은 기획값이다.

|---|---|
| 391–475 | 광개토왕의 확장, 평양 천도, 한성 함락과 웅진 천도 |
| 551–598 | 한강 공방, 신라의 한강 확보, 관산성, 수의 첫 원정 |
| 612–630 | 살수와 후속 원정, 당 건국, 현무문의 변, 동돌궐 원정 |
| 642–657 | 642년 위기, 안시성·을사의 변, 비담의 난, 무열왕 즉위, 서돌궐 원정 |
| 660–676 | 황산벌·사비, 평양·사수, 백강, 고구려 멸망, 나당전쟁·대비천, 임신의 난, 매소성·기벌포 |
| 698–926 | 천문령과 발해 건국, 무왕과 등주, 문왕 초기, 후기 발해와 926년 |

## 발해 확장

- **698년** 동모산을 기반으로 이주민과 인접 집단을 포용한다. 천문령과 건국의 사료를 시작 배경으로 삼고 698년을 플레이 기준 연도로 사용한다.
- **719–737년** 무왕, 흑수말갈, 대문예 망명, 732년 등주 공격을 함께 살핀다. 해상 원정 비용과 변경 세력의 자율성이 승리 조건에 반영된다.
- **737–756년** 문왕의 대외 교섭과 거점 정비를 다룬다. 수도 변경, 중앙 정치와 지방 수송을 묶어 점검한다.
- **756–926년** 장기 확장의 연구 범위다. 당은 907년까지, 거란 요는 916년 이후 활성화한다. 후삼국의 936년 통일은 이 시나리오 밖의 별도 검토 건이다.

연개소문 사망 시점에는 665년과 666년 견해를 함께 표기한다. 660년 사비 공방과 왜의 이후 부흥군 지원은 한 연표에서 이어지되, 왜의 663년 백강 전투를 660년 본전과 구분한다. [삼국사기 보장왕기](https://db.history.go.kr/id/sg_022r_0020_0370) · [일본서기 덴지기](https://www.seisaku.bz/nihonshoki/shoki_27.html) · [신당서 발해전](https://zh.wikisource.org/wiki/新唐書/卷219)

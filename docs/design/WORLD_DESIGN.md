# 해동삼국지 통합 게임 기획

## 시대와 플레이

| 구분 | 범위 | 목적 |
|---|---|---|
| 전기 확장 | 391–475년 주요 사건 | 광개토왕의 확장, 평양 천도, 한성에서 웅진으로 이어지는 재편 |
| 기본 시대 | 551–676년 | 한강 유역부터 나당전쟁 종료 단계까지의 정치·군사 경쟁 |
| 핵심 캠페인 | 612–676년 | 수·당의 원정, 삼국의 외교, 왜의 개혁과 백제 부흥 지원 |
| 기획 시작점 | 642년 1월 | 정변과 대야성 함락 이전의 가상 플레이 시작 조건 |
| 실행 시연 | 645년 | 기존 5국 군령과 소설 초안, 5국 전략 AI 관전 |
| 발해 확장 | 698–926년 | 건국, 무왕·문왕, 후기 발해와 거란의 부상 |

사용자는 한 세력의 군주 또는 임명받은 지휘관으로 정책, 인사, 교섭, 군령을 선택한다. 다른 세력은 같은 시작 상태에서 각자 결정을 낸다. 역사적 시작 배경과 대체 역사 목표는 시나리오 카드에서 별도로 제공한다. 결과로 나온 군령 기록은 기존 소설 초안의 입력으로 사용한다.

## 구현과 사료의 경계

- H는 기록에서 확인할 수 있는 역사적 배경이다. 전승과 이설에는 확인 범위를 붙인다. G는 보존된 게임 기록과 복원 설정, N은 새 게임 시스템과 창작, U는 미확인 자료다. 인물·출처의 A/B/C/U는 [검증 보고서](../history/SOURCES.md)에 정의한다.
- `data/history/`의 세 JSON을 편집하고 `python scripts/build_history.py`로 브라우저 데이터를 생성한다. 정적 페이지와 직접 파일 실행에서 같은 데이터로 시연한다.
- 645년 원본 분기 B, 상대 17일 10시의 START, `ANSI_B_POST_003`은 읽기 전용 참조다. 상대 시각을 절대 역사 날짜로 환산하는 규칙은 미확정이다. 기존 브라우저 군령 저장 키는 `haedong-preview-v1:<id>`다. [기준 엔진 및 시나리오](../HAEDONG_v1.0/README.md)

## 인물 성장·은퇴·귀순

성장 기본값은 `growth`의 연령별 네 능력치를 정수로 보간한다. 경험 획득과 치료·피로는 별도 증감이나 전투 상태로 관리한다. 매력의 성장곡선은 추가 설계 항목이다. 생년 미상 인물의 실제 나이는 표시하지 않으며, 정식 시뮬레이션에 나이가 필요하면 시나리오 가정임을 명시한다.

승계 발생 시 후보의 자격과 공직을 심사하고 개인 충성도·가문 충성도·군단 지휘권을 나누어 재평가한다. 확정 전 상태는 사건 원장에 남긴다. 귀순은 같은 인물 ID에 날짜·기존 소속·새 소속·근거를 추가한다. 군단이나 자원이 인물을 따라가는 변경은 독립 소유권 이벤트로 검증한다.

## 국가 전략과 기존 전투 엔진

```mermaid
flowchart LR
  S[국가 전략 10일] --> A[각 세력 정치·전쟁 제안]
  A --> C[군단 AI의 검증 가능한 군령]
  C --> K[전술 엔진과 사건 원장]
  K --> R[관전·수동·결과 요약]
  K --> S
```

지금의 브라우저 관전은 같은 턴 이전 상태로 다섯 국가와 여섯 변경 세력의 판단을 계산한다. 국가별 정치 제안은 비용과 위험을 비교하고 기존 645년 `replay()`에 유효한 군령을 전달한다. 동일 시드와 군령 이력이 동일한 시연 결과를 내며 자동 관전과 결과 즉시 진행은 같은 상태 전이를 사용한다.

정식 연결에서 `reference_kernel.py`의 권위 시간 단위는 분이다. 전략 단계는 10일, 공성 단계는 하루씩 묶어 사용자에게 보고하고, 야전·수전은 시간 단위의 경과를 집계한다. 엔진의 짧은 이벤트 간격과 긴급 중단은 기존 계약을 따른다. 병력, 보급, 피로, 사기, 지휘, 지형에 이어 해전 조류·풍향을 입력 후보로 둔다. 명령·시드·규칙 버전·결과를 저장하는 전체 전역 엔진 연결은 후속 범위다. 브라우저의 지표 변화와 기준 커널의 병력·포로 원장은 별개의 상태다.

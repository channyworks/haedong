## 검증과 다음 자료 수집

`python -X utf8 -B -m unittest discover -s tests -v`는 ID와 이명, 창작 제외, 출처 필드, 생몰·활동 연대, 소속·가문 링크, 도식, JSON과 공개 번들의 일치를 확인한다. 사료를 확인할 때 해당 기사를 근거로 문장을 갱신하고 생몰·소속·별칭은 따로 근거를 기록한다. 시나리오와 변경 세력의 출처 후보에도 같은 기준을 적용한다. 먼저 642년 시나리오 관련 인물의 활동 시점을 보강하고, 645년 왜 인물의 음독·훈독과 당대 중국 정사 열전의 권차를 확인한다.

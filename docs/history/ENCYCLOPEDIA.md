# 해동삼국지 역사 인물 도감

[통합 인물 도감](../../scenario-preview/index.html#people)에서 모든 수록 항목, 능력치 레이더, 가문, 소속 이력과 사료를 탐색한다. 한글 이름·별칭·원어를 검색할 수 있고 출신·소속·역할·기록 연도·검증 등급으로 필터링한다. 연도 필터에는 확인되거나 자료에 기록된 활동 구간이 쓰인다. 생몰년 미상 인물을 전 연대에 배치하는 데 쓰지 않는다.

## 신규 인물 기록을 작성하는 법

- [인물 JSON](../../data/history/characters.json)의 `person_id`는 변하지 않는 ID다. 이름, 원어와 이명은 `name_ko`, `name_original`, `aliases`에 둔다. 같은 인물의 이름을 추가할 때 기존 ID를 검색한다.
- 생몰년은 양 끝을 포함하는 `[최초, 최후]` 범위다. 한 해가 확실하면 `[연도, 연도]`, 근거가 없으면 `null`이다. `availability`는 도감의 확인 또는 참고 활동 범위다. `origin`과 `affiliations`를 분리하며 연 단위 이력에서 이동한 해는 겹칠 수 있다. `house_id` 속의 친족 그래프는 [국가 JSON](../../data/history/factions.json)의 연결을 참조한다.
- `stats`의 통솔·무력·지력·정치·매력은 게임값이다. `stats_provenance`에 기원을 남기고, `sources`의 기사·근거·판본·접근일과 섞지 않는다. 등록 근거가 없는 값은 `null`이다.
- `legacy_id`와 `legacy_site`는 기존 시연 배역을 연결한다. 역사 도감에 창작 배역을 추가하는 근거로 사용하지 않는다.

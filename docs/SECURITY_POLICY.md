# 보안 및 공개 정책

PoC 기간에는 승인된 범위의 기존 저장소를 Public으로 운영할 예정이다. Pages 아티팩트 네 파일과 저장소 공개는 범위가 다르다. Public 전환으로 모든 접근 가능한 브랜치, Git 변경 이력, 원고·데이터·제작 자료와 커밋 작성자 정보가 공개될 수 있다. 이후 Private으로 바꿔도 외부 복제본·포크·다운로드는 회수할 수 없다.

## 공개 전 검토

- 현재 트리와 접근 가능한 원격 브랜치·태그 이력에서 비밀 키, 토큰, 비밀번호, 환경 파일, 개인정보, 내부 URL과 제한 자료를 검토한다. 바이너리·첨부·압축본은 텍스트 검색 외에 내용과 배포 권리를 따로 확인한다.
- 공개 원고·이미지·데이터 범위를 권리자가 확인한다. 미공개 자료나 식별 정보의 공개 적합성이 확인되지 않으면 전환을 보류한다. 발견 내역에는 유형과 경로만 기록한다.
- 실제 자격 증명 노출 의심 시 공개와 게시를 중단하고 자격 증명을 폐기·교체한다. 이력 정리, 강제 푸시, 기존 자료 삭제는 별도 승인 범위다. 저장소 공개 전환은 사용자가 GitHub UI에서 한다.

## MVP 접근 제어

Pages를 중단하고 저장소를 Private으로 돌린다. OAuth 비밀키는 서버 환경변수 또는 배포 Secret으로 관리한다. 사용자명과 무관하게 GitHub 고유 ID를 기준으로 소유자만 허용한다. 미인증·미인가 요청을 페이지·API·직접 파일·미리보기·개별 배포 URL 모두에서 검사하고 브라우저 번들 또는 공개 스토리지로 제한 콘텐츠가 나가지 않는지 확인한다.
